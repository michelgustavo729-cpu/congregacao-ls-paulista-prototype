CONGREGAÇÃO LS-PAULISTA — PROTÓTIPO PÚBLICO DE INTERFACE

Este é um protótipo de avaliação. Cadastro e edição ficam somente no armazenamento local do navegador. Não existe autenticação, solicitação/aprovação real de administrador, serviço de nuvem, sincronização entre dispositivos ou backup automático. Os dados podem ser perdidos ao limpar dados do navegador.

Não inserir dados pessoais/religiosos reais. Não são fornecidos PDFs oficiais. Não há contas reais nem gestão de usuários.

A sincronização segura exige implementação posterior de backend e autenticação, controle de acesso por administrador, auditoria de permissões, testes de aprovação/revogação, backup/restauração e conflitos. Não conectar dados reais até que isso seja implementado e auditado.
